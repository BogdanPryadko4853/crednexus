# Обучение и сравнение моделей CredNexus

Обучены CatBoost, LightGBM и XGBoost для двух кредитных таргетов и двух денежных потоков. Выбор параметров и весов ансамбля сделан по validation; отложенные test и stress_test используются для итогового измерения качества.

**Данные полностью синтетические. Эти метрики подтверждают работу прототипа на симуляторе, но не качество банковского скоринга на реальных клиентах. Название SOTA не гарантирует победу на конкретном датасете.**

## Эксперимент

Генератор 0.2.1, manifest SHA256 `661848a84844acd010c96b1e09674b05f61f8605df41d25b523964bb57c6d0bc`. Seed 20261021. Только CPU, 4 потока на процесс. Гиперпараметры: Optuna TPE, 12 попыток на семейство/кредитный таргет и 8 на семейство/прогнозный таргет. Early stopping по validation. Train, validation и test разделены по компаниям и времени; labels дозрели до следующей когорты.

CRC32(company_id)%10 < 7 определяет часть validation для подбора моделей/ансамбля; остальные компании validation используются для Platt-калибровки скоринга и эмпирических интервалов прогноза. В прогнозных таблицах есть повторные origins одной компании: строки не являются независимыми наблюдениями.

Параметры, все trial scores, native weights, schemas, registries и построчные predictions сохранены в `artifacts/benchmark_v1`. Модель может использовать только признаки на дату origin. Скрытые параметры симулятора, будущие состояния и будущий макропуть исключены. Добавлены финансовые отношения и значение потока в прошлом году для прогнозируемого месяца.

Обучающая панель рядов: train: 480,000, test: 434,508, stress_test: 383,532, validation: 80,000. HPO обучается на фиксированных 120 000 train-строках; затем проверяется refit на 480 000. Сохраняется вариант с меньшим validation WAPE. Test и stress_test взяты полностью из соответствующих forecast cohorts.

## Chronos-2: отдельное сравнение на общей панели

Проверены zero-shot small/base и полное дообучение small на CPU (200 и 1000 шагов, batch size 32, LR 1e-5). Обновления весов используют только train-компании, месяцы не позже 47; 4000 многомерных историй. Вход: поступления, выплаты, продажи, расходы и остаток; контекст до 48 месяцев, прогноз 3 месяца.

Пиковый RSS проверочного процесса: 1958 MiB. Измерение включает загрузку данных для проверки; inference в приложении не требует всего датасета. Время зависит от процессора и нагрузки. Для всех трёх семейств и четырёх таргетов predictions после загрузки native weights проверены против сохранённых тестовых predictions на 1024 строках; допустимая относительная ошибка 1e-6.

Обучение scoring: пик RSS 1491 MiB; wall time 1:51.35. Это ресурсы отдельного процесса; параллельные эксперименты суммируют память.

Обучение forecast: пик RSS 4151 MiB; wall time 23:40.95. Это ресурсы отдельного процесса; параллельные эксперименты суммируют память.

Скоринг продолжался из сохранённых завершённых поисков параметров. Его wall time относится к заключительному процессу и не включает предыдущие поиски. Замеры выполнены на AMD Ryzen 5 7500F с лимитом 4 потока на ML-процесс; на другом офисном CPU время будет отличаться.

## Ограничения и использование

Окончательный выбор сравнивает только реально обученные конфигурации при ограниченном CPU-бюджете. Это не исчерпывающий поиск и не доказательство глобального SOTA. Для демо используйте `crednexus_ml.inference.Predictor`: модель хранится в памяти между запросами, API и GPU не нужны. Локальные файлы весов, schema и registry обязательны; ключи внешних LLM для этого ML-кода не используются.

На реальных данных потребуются переобучение, отдельный out-of-time тест и повторная калибровка. Не принимайте кредитные решения по этим синтетическим вероятностям. Ошибки распознавания документов здесь не моделируются как качество OCR; в обучении используется основное observed-представление, не таблицы с грубыми искусственными повреждениями.

Версии библиотек и dataset fingerprint: `artifacts/benchmark_v1/run.json`; команды повторного запуска и контракт входов: `docs/MODELS.md`.

# CredNexus — общая дизайн-система

## Источники и границы

Визуальная основа: белые поверхности, светло-серый фон, тёмная типографика,
красный акцент, крупные читаемые заголовки и спокойная плотность форм.

Публичные источники:

- [Раздел Альфа-Банка для бизнеса](https://alfabank.ru/sme/).
- [Палитра Core Components](https://github.com/core-ds/core-components/blob/master/packages/vars/src/colors-bluetint.css).
- [Документация цветов](https://core-ds.github.io/core-components/master/?path=/docs/guidelines-colors--docs).
- [Документация типографики](https://core-ds.github.io/core-components/master/?path=/docs/guidelines-typography--docs).

Фирменный акцент `#EF3124` и основные поверхности сверены с открытыми токенами.
Для белого текста на основных кнопках используется более тёмный красный
`#E32A17` из той же палитры: контраст небольшого текста должен быть не ниже 4.5:1.
Цвета статусов также разделены на фон и читаемый текст. Контраст этих пар
проверяется автоматически. Отключённые элементы не используются для важной информации.

Шкалы отступов, размеров и структура компонентов — проектные решения CredNexus,
а не заявление об официальном корпоративном стандарте. Прямая визуальная
проверка актуального сайта банка ограничена ошибкой доступа к сайту.
Официальный логотип, внешние шрифты и закрытые ресурсы не используются.
Знак C в заголовке — самостоятельное текстовое обозначение CredNexus.

## Токены

Единственный источник токенов — `src/styles/tokens.css`.

| Категория         | Значения                                             |
| ----------------- | ---------------------------------------------------- |
| Акцент            | `--color-brand: #EF3124`                             |
| Основное действие | `--color-action: #E32A17`; hover `#D72505`           |
| Поверхности       | `#FFFFFF`, фон `#F2F3F5`                             |
| Текст             | `#212124`, вторичный `#62626A`                       |
| Шрифт             | system-ui, системные замены; без загрузки шрифтов    |
| Основной текст    | 16 px; вспомогательный 14 px; line-height 1.5        |
| Заголовки         | 24, 32 px; демонстрационный крупный 32–56 px         |
| Отступы           | 4, 8, 12, 16, 24, 32, 48, 64 px                      |
| Скругления        | 8 px вспомогательные, 12 px контролы, 20 px карточки |
| Контролы          | поле от 52 px; кнопка от 48 px, компактная от 40 px  |
| Фокус             | видимая синяя рамка 3 px с отступом                  |

Глобальный CSS подключается один раз в `src/main.tsx`. Стили компонентов
находятся в `src/styles/components.css`; оформление формы отдельно в
`src/app/application/application.css` и не требуется самим компонентам.

## Компоненты

Импорт: `import { Button, TextField } from './components'` с подходящим относительным путём.

| Компонент                                   | Контракт и правила                                                                                                                                                                                                                      |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Heading`, `Text`                           | Уровень заголовка выбирается по структуре документа; визуальный размер задаётся отдельно                                                                                                                                                |
| `Button`                                    | `variant`: primary/secondary/ghost, `size`: md/sm. По умолчанию `type="button"`; отправка формы требует явного submit. `loading` блокирует повторное действие, сохраняет название и устанавливает aria-busy                             |
| `TextField`, `SelectField`, `TextareaField` | Обязательная видимая подпись; стабильный уникальный ID; `hint`, `error`, aria-invalid и объединение aria-describedby. Нативные свойства полей сохраняются                                                                               |
| `Card`                                      | Заголовок, пояснение, действие и footer необязательны; компонент не содержит бизнес-логики                                                                                                                                              |
| `Icon`                                      | Самостоятельные SVG без внешних ресурсов. Декоративные; кнопка со значком без текста обязательно получает aria-label                                                                                                                    |
| `StatusBadge`                               | Тон neutral/info/positive/attention/negative. Значение всегда задаётся текстом, значок дополнительно отличает состояния. Не выполняет переходы статусов                                                                                 |
| `Alert`                                     | Текст и заголовок. По умолчанию статический; role=status или role=alert добавляется вызывающим кодом только для динамического сообщения                                                                                                 |
| `Spinner`, `Skeleton`                       | Загрузка имеет текстовое описание; скелетоны декоративны. Учитывается prefers-reduced-motion                                                                                                                                            |
| `PageState`                                 | loading/error/empty, заголовок, пояснение и необязательное действие. Ошибка объявляется через alert                                                                                                                                     |
| `DataTable<Row>`                            | Обязательные caption и rowKey, типизированные колонки. Семантическая таблица; суммы выравниваются справа. При отсутствии строк показывается пояснение. На узком экране таблица прокручивается внутри доступного с клавиатуры контейнера |
| `Modal`                                     | Управляемые open/onClose. Нативный dialog/showModal: изоляция фона и удержание фокуса средствами браузера. Escape, крестик, фон закрывают; закрытие возвращает фокус. Вложенные модальные окна не предусмотрены                         |

Валюта, сроки, проверки и право действия приходят из соответствующих бизнес-модулей.
Компоненты не принимают кредитных решений и не подменяют серверные права.

## Правила использования

- Одно основное действие в смысловом блоке. Остальные — secondary или ghost.
- Ошибка относится к конкретному полю; введённые значения не теряются.
- Техническая ошибка источника не обозначается как отказ в кредите.
- Статус передаётся текстом и значком, а не одним цветом.
- Длинные формы размещаются на странице; Modal предназначен для короткого подтверждения.
- Таблица сохраняет семантику на мобильных устройствах. Горизонтальная прокрутка
  ограничена контейнером таблицы; страница не должна выходить за ширину окна.
- При отключённой анимации состояние остаётся понятным по тексту.
- При смене крупной страницы используется та же система токенов и компонентов.

## Основной экран

Корневой экран — форма заявки с пустыми полями, пояснениями и проверкой формата.
Образцы состояний полей, кнопок и списков в пользовательском интерфейсе
не выводятся. Ошибки возникают только при проверке введённых значений.
Данные находятся в памяти страницы и сбрасываются после перезагрузки;
серверные запросы и банковские операции отсутствуют.
Сведения о текущих ограничениях находятся в документации.

## Проверка

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run dev
```

В браузере проверить: ширины 360/390/768 px и обычное окно компьютера,
Tab/Shift+Tab в Modal, Escape и возврат фокуса, закрытие нажатием на фон,
валидацию и сохранность формы и отсутствие ошибок консоли.
Таблица, статусы и состояния остаются общими компонентами с модульными тестами,
но не выводятся как образцы на основном экране.
Автоматические тесты jsdom не заменяют проверку
нативного модального поведения в браузере.

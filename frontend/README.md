# CredNexus Frontend

## Текущий объём: FE-001 и FE-002

Основа приложения на React, TypeScript и Vite и общая дизайн-система.
Корневой экран — форма заявки на финансирование с пустыми полями.
Витрина компонентов, заранее заданные ошибки и вымышленные заявки не выводятся.
Форма работает в памяти страницы, без отправки на сервер. Маршрутизация,
авторизация и API будут следующими задачами.
Для запуска этой версии backend и Keycloak не требуются.

Компоненты и правила использования: [design-system.md](./design-system.md).

## Окружение

- Node.js от 24.15.0 до конца ветки 24.x (минимум для jsdom).
- npm 11.x; для воспроизводимости рекомендуется npm 11.21.1.
- Современный браузер.

Версии прямых зависимостей закреплены в `package.json`, дерево зависимостей —
в `package-lock.json`. Используйте npm, чтобы сохранять один формат lock-файла.

## Локальный запуск

Выполните из корня репозитория:

```sh
cd frontend
npm ci
npm run dev
```

Откройте <http://localhost:5173>. Сервер слушает только локальный интерфейс.
При занятом порте запуск завершится с ошибкой вместо перехода на другой порт.
Адрес 5173 соответствует существующей конфигурации клиента Keycloak.

## Проверки и сборка

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

`typecheck` проверяет исходники приложения и конфигурацию Vite в отдельных
TypeScript-проектах. Тесты проверяются отдельным проектом с типами Node.js и DOM,
которые не добавляются к браузерному приложению. `build` сначала выполняет эту проверку, затем создаёт
production-файлы в `dist/`. `preview` показывает уже собранную версию по адресу
<http://localhost:4173>; это инструмент локальной проверки сборки.

Проверка в браузере: отображается «Заявка на финансирование».
Поля изначально пустые; ошибка появляется после проверки неверного ввода.
Для ручной проверки используйте только синтетические сведения, например
название «ООО Маяк», ИНН `0000000000` и сумму `1500000`.
Кнопка «Проверить данные» открывает подтверждение только для корректно
заполненных полей. Кнопка «Подтвердить» подтверждает проверку заполнения,
но не сохраняет и не отправляет заявку в банк. Модальное окно закрывается
через Escape с возвратом фокуса; введённое при отмене сохраняется.
После перезагрузки форма очищается.

Vitest и Testing Library проверяют поведение компонентов, ошибки и подтверждение
формы. Отдельные тесты контролируют контраст цветовых пар. Нативная изоляция
фокуса в dialog дополнительно проверяется в настоящем браузере.

## Структура

```text
src/
  app/              — корневой компонент и форма заявки
  components/       — общие контролы и блоки
  styles/           — токены, глобальные и компонентные стили
  test/             — настройка проверок
  main.tsx          — точка входа React
  vite-env.d.ts     — типы окружения Vite
vite.config.ts      — React-плагин и локальные порты
vitest.config.ts    — тесты в jsdom
tsconfig*.json      — строгая проверка приложения, тестов и конфигураций
```

Новые модули добавляются по мере реализации. Генерируемые файлы, зависимости
и локальные переменные окружения исключены через `frontend/.gitignore`.

## Ограничения

Реализованы интерфейс формы и клиентская проверка заполнения. Авторизация,
серверное сохранение, проверки компании, решения и выдача не реализованы.
Внешний вид не означает готовности серверного кредитного процесса.
Общий Docker-запуск запланирован в FE-005.
